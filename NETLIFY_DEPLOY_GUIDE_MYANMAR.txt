====================================================================
HEIN HTET AUNG PORTFOLIO — NETLIFY တွင် ပုံများ အမြဲတမ်း ပေါ်စေရန် နည်းလမ်း (၂) သွယ်
====================================================================

နည်းလမ်း (၁) — Netlify Drop (ကုဒ်ရေးစရာ လုံးဝမလိုသော အလွယ်ဆုံးနည်းလမ်း)
--------------------------------------------------------------------
၁။ ဤ ZIP ဖိုင်ကို သင့်ကွန်ပျူတာတွင် ဖြည် (Extract) လိုက်ပါ။
၂။ Terminal သို့မဟုတ် Command Prompt တွင် အောက်ပါ command (၂) ကြောင်း ရိုက်ပါ-
      npm install
      npm run build
၃။ Build လုပ်ပြီးပါက "dist" အမည်ရှိ folder တစ်ခု ထွက်လာပါမည်။
၄။ Browser တွင် https://app.netlify.com/drop သို့ သွားပါ။
၅။ "dist" folder ကို ကွန်ပျူတာထဲမှ ဆွဲယူပြီး Drop Zone ထဲသို့ ဆွဲချ (Drag & Drop) လိုက်ပါ။
၆။ စက္ကန့်ပိုင်းအတွင်း Netlify Link ထွက်လာပြီး ဓာတ်ပုံများ၊ Certificates များ အားလုံး အပြည့်အစုံ ပေါ်နေမည် ဖြစ်ပါသည်။

နည်းလမ်း (၂) — GitHub မှတစ်ဆင့် Netlify သို့ ချိတ်ဆက်တင်နည်း
--------------------------------------------------------------------
၁။ ဤ ZIP ဖိုင်ထဲမှ ဖိုင်အားလုံးကို သင့် GitHub Repository အသစ်ထဲသို့ Push/Upload လုပ်ပါ။
၂။ Netlify (https://app.netlify.com) တွင် "Add new site" > "Import an existing project" > GitHub ကို ရွေးပါ။
၃။ သင့် repository ကို ရွေးပေးပြီး "Deploy site" ကို နှိပ်ပါ။
၄။ Build settings တွင်:
      Base directory: (blank ထားပါ)
      Build command: npm run build
      Publish directory: dist
၅။ အလိုအလျောက် Live ဖြစ်သွားပါမည်။

ဓာတ်ပုံများနှင့် ပတ်သက်၍-
--------------------------------------------------------------------
• ဤ ZIP ထဲတွင် "public/images" folder ပါရှိပြီး ဓာတ်ပုံများ အားလုံး ထို folder ထဲတွင် သီးသန့် အဆင်သင့် ပါဝင်ပြီး ဖြစ်ပါသည်။
• အကယ်၍ နောင်တွင် ဓာတ်ပုံအသစ် လဲလိုပါက "public/images" ထဲသို့ သွား၍ ပုံအသစ် ထည့်ပေးရုံဖြင့် အလိုအလျောက် ပြောင်းလဲပါမည်။
